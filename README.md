# Student Monitoring System

A simple mobile-friendly student monitoring and attendance demo inspired by the MIT App Inventor screen provided.

## Features
- Dashboard showing total registered students and today's present/absent counts
- Add student information (student ID, name, course/section)
- Record daily attendance as Present or Absent
- View attendance reports by date or show all records
- Saves demo data in the browser using localStorage

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Open the URL GitHub Pages provides.

## Note
This is a front-end demonstration, not a production attendance database or an MIT App Inventor `.aia` project. Data is stored only in the current browser on the device and is not shared between users.
